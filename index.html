Code de déverrouillage

Code à 3 chiffres (1–9), tapé sur le bouton du guidon : 159 = 1 appui · pause · 5 appuis · pause · 9 appuis. ⚠️ La lecture ne renvoie pas le code stocké (sécurité) — la seule vraie vérification est de le taper sur un vélo complet. Tu peux toujours déverrouiller via l'appli.
